# Architecture Decision Records (ADR) Index

This directory contains records of significant architectural decisions made for the Smart-Work-Tracking repository.

AI agents and team members act upon these constraints. A new ADR must be introduced whenever:

- Architecture changes
- New dependencies are introduced
- Database design changes
- Security models change
- Integration patterns change
