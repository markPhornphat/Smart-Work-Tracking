# Prompt Template: Refactoring

## Prompt
```md
Refactor the target code while preserving behavior.

Constraints:
- Follow docs/architecture.md and docs/coding-standards.md.
- Prefer composition over inheritance.
- Reduce duplication and tighten module boundaries.
- Keep side effects explicit.
- Maintain or improve test coverage.

Return:
- Refactoring strategy
- Before/after structure summary
- Safety checks and regression test plan
```
