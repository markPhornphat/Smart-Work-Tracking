# Prompt Template: Architecture Review

## Prompt
```md
Review the architecture for feature/module: <MODULE_NAME>.

Evaluate:
- Clean Architecture compliance
- DDD boundaries and aggregate design
- Coupling/cohesion
- Event-driven readiness
- API-first contract quality
- Microservice migration readiness

Return:
- Violations and risks
- Recommended target design
- Migration steps and ADR suggestions
```
