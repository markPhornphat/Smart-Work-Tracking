# Prompt Template: Security Audit

## Prompt
```md
Perform a security audit for: <SCOPE>.

Check:
- OWASP Top 10 risks
- AuthN/AuthZ correctness
- Input validation and output encoding
- Secret handling and configuration safety
- Error leakage and logging hygiene

Return:
- High/medium/low findings
- Exploit scenario summary
- Remediation plan with priorities
- Required test/security checks
```
