# Prompt Template: Performance Optimization

## Prompt
```md
Perform a performance review for: <SCOPE>.

Requirements:
- Keep correctness and business rules intact.
- Profile bottlenecks before optimizing.
- Consider algorithmic complexity, I/O, and DB access.
- Avoid architecture boundary violations.
- Add benchmark/measurement evidence.

Return:
- Bottleneck findings
- Proposed optimizations with impact estimate
- Trade-offs and rollback strategy
- Test/monitoring plan
```
